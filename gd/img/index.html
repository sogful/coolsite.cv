Spend the object budget

The fitter samples each captured native texture’s alpha and shading instead of treating an object as a solid mask. It searches different mesh shapes, rotation, independent X/Y scale and, optionally, the game’s 2.2 axis warp against the remaining image error. Multi-colour objects get separate base and detail fits. The default HSV method keeps the palette to one red source channel, 999, while each object stores its own base/detail hue, saturation and brightness.
